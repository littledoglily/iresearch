# burst trie 分块算法:脱离项目的逐步例子

> 对应源码:`field_writer::Push` / `WriteBlocks` / `WriteBlock`([formats_burst_trie.cpp](../core/formats/formats_burst_trie.cpp))。
> 本文把算法当成一个独立的小问题来讲,不涉及 `.tm` / `.doc` 的具体字节。每一步的状态都和一个按真实 `Push` 逻辑写的小模拟逐步核对过。
> 与项目里的例子对照见 [field_write_memory_flush_pipeline.md](field_write_memory_flush_pipeline.md) 的 3.3.2.1 ~ 3.3.2.4。

## 1. 要解决的问题

有一批**已经排好序**的单词,要把它们按前缀分成"块",满足:

- 只扫描一遍,内存里只保留"还没处理完"的部分;
- 共享前缀的单词尽量放进同一个块,块里只存去掉前缀后的剩余部分;
- 一个前缀下的单词太少,就不值得单独建块。

## 2. 三样东西

把它想成**桌上摞卡片**:

| 名字 | 源码里的名字 | 含义 |
|---|---|---|
| 卡片堆 `stack` | `stack_` | 每个单词是一张卡片,依次放上去。堆里还可以出现"块卡片",它代表一整组已经打包好的单词,**只占一个位置** |
| `last` | `last_term_` | 上一张放上去的单词 |
| 书签数组 `bookmarks` | `prefixes_` | 见下 |

### 书签数组的含义

**第 `i` 项记录"前 `i+1` 个字符这个前缀,在卡片堆里从第几个位置开始"。**

1. **下标 `i` 对应前缀长度 `i+1`。** `i=0` 是第 1 个字符,`i=1` 是前 2 个字符,依此类推。数组长度等于**最近一次 `Push` 的单词长度**,最后一项对应单词本身。
2. **值是堆里的位置(下标)。** 表示:堆里从这个下标开始,往上到堆顶,都是以该前缀开头的条目。
3. **只需要"起点"。** 单词是排好序的,同一前缀的条目一定连续,而且一定挨着堆顶。起点记一次,终点永远是堆顶。

所以:

```text
一个前缀下积压了多少张卡片 = 当前堆高 − 这个前缀的书签        (源码里叫 top)
```

书签只存在于 flush 时 `field_writer` 的内存里,不写进任何文件。

## 3. 规则

阈值记作 `T`(源码里是 `min_block_size_`,默认 25):某前缀下积压 `top > T` 才成块。

每来一个新单词 `w`,完整动作按顺序是:

| 编号 | 动作 |
|---|---|
| a | 求 `w` 与 `last` 的公共前缀长度 `pos` |
| b | 确定要检查的前缀:`i` 从 `len(last)−1` 开始,**每次先 `i−1` 再检查**,直到 `i == pos` 为止。所以被检查的 `i` 范围是 `len(last)−2` 到 `pos`,对应长度 `i+1` 的前缀。范围为空就不检查 |
| c | 逐个计算 `top = 堆高 − 书签[i]`,判断 `top > T` |
| d | 如果成块:取出堆顶 `top` 张卡片,写成一个块,从堆里删掉这 `top` 张,把新块卡片压回堆顶。随后源码做 `书签[i] -= top−1` |
| e | `书签` 数组 `resize` 成 `len(w)` 项 |
| f | 从下标 `pos` 到末尾,把书签全部设成**此刻的堆高** |
| g | `last = w` |
| h | 把 `w` 压到堆顶 |

所有单词处理完后,来一个**空串** `Push("")`,让所有前缀都结束;最后把堆里剩下的条目整体写成**根块**。

两个要点:

- **为什么只和上一个单词比。** 单词已排序,一旦新单词在某个位置与上一个分叉,上一个单词在该位置之后的所有前缀都**再也不会出现**。结束的前缀只会出现在上一个单词的"分叉点之后"。
- **为什么只检查真前缀。** 单词本身(例如 `cave`)下面只会有它自己,`top` 恒为 1,不会成块。所以检查的 `i` 最大是 `len(last)−2`;书签数组里仍保留单词本身那一项,只是为了让下标和前缀长度对齐。

## 4. 例子

单词(已排序):`cab, cat, cave, cow, dog, dot, dove`,阈值 `T = 2`,即积压超过 2 张(≥ 3)才成块。

表示法:堆写成 `下标:内容`,`{ca}` 表示块卡片;书签数组下标 0、1、2… 对应长度 1、2、3… 的前缀。

### 初始状态

```text
堆: []   堆高 0
last: ""
书签: []
```

### 步骤 1:`Push("cab")`

| 动作 | 结果 |
|---|---|
| a | `last=""`,没有可比较的字符,`pos = 0` |
| b | `last` 为空时 `i` 初始为 0,条件 `i > pos` 即 `0 > 0` 不成立,**没有前缀要检查** |
| c、d | 无 |
| e | `resize(3)`:书签从 `[]` 变成 `[0,0,0]` |
| f | 从下标 0 到末尾设成堆高 0:`[0,0,0]` |
| g | `last = "cab"` |
| h | 压入 `cab` |

```text
结束后  堆: [0:cab]  堆高 1
        书签: [0,0,0]    ← c→0, ca→0, cab→0
```

### 步骤 2:`Push("cat")`

| 动作 | 结果 |
|---|---|
| a | `cab` 与 `cat`:`c`、`a` 相同,`b ≠ t`,`pos = 2` |
| b | `i` 从 `3−1 = 2` 开始,条件 `2 > 2` 不成立,**没有前缀要检查**(`cab` 比 2 更长的只有 `cab` 本身,而单词本身不检查) |
| c、d | 无 |
| e | `resize(3)`,仍是 `[0,0,0]` |
| f | 从下标 2 起设成堆高 1:`[0,0,1]` |
| g | `last = "cat"` |
| h | 压入 `cat` |

```text
结束后  堆: [0:cab  1:cat]  堆高 2
        书签: [0,0,1]    ← c→0, ca→0, cat→1
```

### 步骤 3:`Push("cave")`

| 动作 | 结果 |
|---|---|
| a | `cat` 与 `cave`:`c`、`a` 相同,`t ≠ v`,`pos = 2` |
| b | `i` 从 2 开始,`2 > 2` 不成立,**没有前缀要检查** |
| c、d | 无 |
| e | `resize(4)`:从 `[0,0,1]` 变成 `[0,0,1,0]` |
| f | 从下标 2 起设成堆高 2:`[0,0,2,2]` |
| g | `last = "cave"` |
| h | 压入 `cave` |

```text
结束后  堆: [0:cab  1:cat  2:cave]  堆高 3
        书签: [0,0,2,2]    ← c→0, ca→0, cav→2, cave→2
```

### 步骤 4:`Push("cow")`,第一次成块

| 动作 | 结果 |
|---|---|
| a | `cave` 与 `cow`:`c` 相同,`a ≠ o`,`pos = 1` |
| b | `i` 从 `4−1 = 3` 开始。先 `i−1`:`i=2` → 前缀 `cav`;再 `i−1`:`i=1` → 前缀 `ca`;`i=1 > 1` 不成立,结束 |
| c(`cav`,i=2) | `top = 堆高 3 − 书签[2]=2 = 1`,`1 ≤ 2`,不成块 |
| c(`ca`,i=1) | `top = 堆高 3 − 书签[1]=0 = 3`,`3 > 2`,**成块** |
| d | ① 取出堆顶 3 张:`cab, cat, cave`;② 写成一个块,前缀 `ca`,块里只存后缀 `b`、`t`、`ve`;③ 从堆里删掉这 3 张;④ 把块卡片 `{ca}` 压回堆顶。堆变成 `[0:{ca}]`,堆高 1。随后 `书签[1] -= 3−1`,`0−2` 无符号回绕成一个大数,**但下一步 f 会覆盖它** |
| e | `resize(3)`:书签从 `[0,大数,2,2]` 截成 `[0,大数,2]` |
| f | 从下标 1 起设成堆高 1:`[0,1,1]` |
| g | `last = "cow"` |
| h | 压入 `cow` |

```text
结束后  堆: [0:{ca}  1:cow]  堆高 2
        书签: [0,1,1]    ← c→0, co→1, cow→1
```

`书签[0]=0` 没变:前缀 `c` 的起点仍是位置 0,因为块 `{ca}` 现在占着位置 0。

### 步骤 5:`Push("dog")`,检查但不成块

| 动作 | 结果 |
|---|---|
| a | `cow` 与 `dog`:第一个字符就不同,`pos = 0` |
| b | `i` 从 `3−1 = 2` 开始。`i=1` → 前缀 `co`;`i=0` → 前缀 `c`;`0 > 0` 不成立,结束 |
| c(`co`,i=1) | `top = 堆高 2 − 书签[1]=1 = 1`,`1 ≤ 2`,不成块 |
| c(`c`,i=0) | `top = 堆高 2 − 书签[0]=0 = 2`,`2 ≤ 2`,**不成块**(`{ca}` 和 `cow` 各算 1 张,共 2 张) |
| d | 无 |
| e | `resize(3)`,仍是 3 项 |
| f | 从下标 0 起设成堆高 2:`[2,2,2]` |
| g | `last = "dog"` |
| h | 压入 `dog` |

```text
结束后  堆: [0:{ca}  1:cow  2:dog]  堆高 3
        书签: [2,2,2]    ← d→2, do→2, dog→2
```

### 步骤 6:`Push("dot")`

| 动作 | 结果 |
|---|---|
| a | `dog` 与 `dot`:`d`、`o` 相同,`g ≠ t`,`pos = 2` |
| b | `i` 从 2 开始,`2 > 2` 不成立,**没有前缀要检查** |
| c、d | 无 |
| e | `resize(3)`,仍是 3 项 |
| f | 从下标 2 起设成堆高 3:`[2,2,3]` |
| g | `last = "dot"` |
| h | 压入 `dot` |

```text
结束后  堆: [0:{ca}  1:cow  2:dog  3:dot]  堆高 4
        书签: [2,2,3]    ← d→2, do→2, dot→3
```

### 步骤 7:`Push("dove")`

| 动作 | 结果 |
|---|---|
| a | `dot` 与 `dove`:`d`、`o` 相同,`t ≠ v`,`pos = 2` |
| b | `i` 从 2 开始,`2 > 2` 不成立,**没有前缀要检查** |
| c、d | 无 |
| e | `resize(4)`:从 `[2,2,3]` 变成 `[2,2,3,0]` |
| f | 从下标 2 起设成堆高 4:`[2,2,4,4]` |
| g | `last = "dove"` |
| h | 压入 `dove` |

```text
结束后  堆: [0:{ca}  1:cow  2:dog  3:dot  4:dove]  堆高 5
        书签: [2,2,4,4]    ← d→2, do→2, dov→4, dove→4
```

### 步骤 8:字段结束,`Push("")`,第二次成块

| 动作 | 结果 |
|---|---|
| a | `dove` 与空串没有公共前缀,`pos = 0` |
| b | `i` 从 `4−1 = 3` 开始。`i=2` → 前缀 `dov`;`i=1` → 前缀 `do`;`i=0` → 前缀 `d`;`0 > 0` 不成立,结束 |
| c(`dov`,i=2) | `top = 堆高 5 − 书签[2]=4 = 1`,不成块 |
| c(`do`,i=1) | `top = 堆高 5 − 书签[1]=2 = 3`,`3 > 2`,**成块** |
| d | ① 取出堆顶 3 张:`dog, dot, dove`;② 写成一个块,前缀 `do`,只存后缀 `g`、`t`、`ve`;③ 从堆里删掉这 3 张;④ 压回块卡片 `{do}`。堆变成 `[0:{ca}  1:cow  2:{do}]`,堆高 3。随后 `书签[1] -= 3−1`,`2−2 = 0`,之后会被覆盖 |
| c(`d`,i=0) | `top = 堆高 3 − 书签[0]=2 = 1`,`1 ≤ 2`,不成块 |
| e | `resize(0)`:书签变成 `[]` |
| f | 没有元素可填 |
| g | `last = ""` |
| h | 空串只是结束标记,**不压栈** |

```text
结束后  堆: [0:{ca}  1:cow  2:{do}]  堆高 3
        书签: []
```

### 步骤 9:写根块

`EndField` 接着调用 `WriteBlocks(0, 3)`:把堆里剩下的 3 个条目 `{ca}`、`cow`、`{do}` 写成根块,前缀为空串。

最终结构:

```text
根块  [ {ca}, cow, {do} ]
         │            │
         ▼            ▼
   块 {ca}: [b, t, ve]    块 {do}: [g, t, ve]
```

|---|---|---|---|---|---|---|
| 1 | `cab` | 0 | 无 | — | `[cab]` | `[0,0,0]` |
| 2 | `cat` | 2 | 无 | — | `[cab, cat]` | `[0,0,1]` |
| 3 | `cave` | 2 | 无 | — | `[cab, cat, cave]` | `[0,0,2,2]` |
| 4 | `cow` | 1 | `cav`(1),`ca`(**3**) | **`ca` 成块** | `[{ca}, cow]` | `[0,1,1]` |
| 5 | `dog` | 0 | `co`(1),`c`(2) | 不成块 | `[{ca}, cow, dog]` | `[2,2,2]` |
| 6 | `dot` | 2 | 无 | — | `[{ca}, cow, dog, dot]` | `[2,2,3]` |
| 7 | `dove` | 2 | 无 | — | `[{ca}, cow, dog, dot, dove]` | `[2,2,4,4]` |
| 8 | `""` | 0 | `dov`(1),`do`(**3**),`d`(1) | **`do` 成块** | `[{ca}, cow, {do}]` | `[]` |
| 9 | — | — | — | 写根块 | `[根块]` | — |

## 6. 从例子得到的结论

1. **写入顺序是子块在前、父块在后。** `{ca}` 在步骤 4 就写进了文件,`{do}` 在步骤 8,根块最后。子块的起点比父块小,所以父块里存的是"到子块的相对偏移",源码里有 `block_start > e.block().start` 的断言。
2. **步骤 2、3、6、7 都没有检查。** 这些步骤里新单词和上一个单词只在最后一个字符上分叉,上一个单词比 `pos` 更长的只有它自己,单词本身不检查。
3. **步骤 5 的 `c` 是"差一点"的例子。** `c` 下面有 `{ca}` 和 `cow`,共 2 张,不超过 `T=2`,所以不成块。它说明**块卡片只算 1 张**,这是块可以嵌套的前提。
4. **成块之后 `书签[i] -= top−1` 是多余的。** 因为被检查的 `i` 总是 `≥ pos`,紧接着的 `fill` 会覆盖从 `pos` 起的所有项,所以无符号回绕不会造成影响。较短前缀的书签(例如步骤 4 之后的 `c→0`)不受影响,仍然有效。

## 7. 与真实代码的对应

| 例子里的名字 | 源码 |
|---|---|
| 卡片堆 | `stack_` |
| 书签数组 | `prefixes_` |
| `last` | `last_term_` |
| 阈值 `T` | `min_block_size_`,默认 25(`max_block_size_` 默认 48) |
| 成块 | `WriteBlocks(前缀长度, top)`,里面调 `WriteBlock` 写 `.tm` |
| 放空串收尾 | `EndField` 里的 `Push(kEmptyStringView)`,随后 `WriteBlocks(0, stack_.size())` 写根块 |

真实代码里还有两处这个例子没有涉及:

- 如果一个前缀下积压超过 `max_block_size_`(默认 48),`WriteBlocks` 会按下一个字符把它拆成多个 "floor" 块;
- 如果某个单词本身又是另一个单词的前缀(例如 `car` 与 `card`),单词本身在块里作为一个"标签无效"的条目处理(`INVALID_LABEL`)。
